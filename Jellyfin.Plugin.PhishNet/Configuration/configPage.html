Chapter Markers

Adds a chapter for each song by matching the video's audio to track audio from phish.in, the Phish audio archive. Thanks to phish.in for the audio. Show data comes from Phish.net. Chapters go into Jellyfin's database; video files are never changed.

Off by default. Each show reads its whole video file once and downloads the first 90 seconds of every track from phish.in.
When off, only the "Phish: add chapter markers" scheduled task adds them (daily at 4:00 by default; change it under Scheduled Tasks).
Real chapters, from the file or added by hand, are never replaced.
How many shows one scheduled run aligns. Library changes share the same allowance per day.
Stops the run once this much video has been read, so a first run on a big library is spread over several nights.

To set a show's chapters by hand, put a text file named like the video with .chapters.txt in place of its extension next to it (for example ph2026-07-07.chapters.txt next to ph2026-07-07.mkv), with one H:MM:SS Title per line. It replaces alignment for that show.
